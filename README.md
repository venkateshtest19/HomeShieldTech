# HomeShieldTech — Vercel static website

## Deployment
Upload this folder to a GitHub repository and import it in Vercel as an **Other** framework / static project. No build command is required.

## Before publishing
1. Confirm the exact address formatting: `3rd 5th Ave, New York, NY 10011, USA` is reproduced exactly as provided but appears ambiguous.
2. Confirm that +1 551-382-8836 is the business contact number.
3. Provide a HomeShieldTech email or a form-processing endpoint. The enquiry form is intentionally disabled until submissions can be received reliably.
4. Configure a HomeShieldTech Tawk.to property if live chat is required. The original Safe Home chat property is not embedded to prevent routing conversations to another brand.
5. Obtain authorized Best Buy affiliate parameters. The current product links are clean retailer URLs, **not affiliate-tracked links**. Do not reuse Safe Home tracking identifiers without permission.
6. Verify current Best Buy products, compatibility, subscription terms and availability.
7. Configure GA4 / Google Ads with actual measurement IDs. The JS emits `click_to_call` and `affiliate_outbound_click` to dataLayer if a tag manager is installed; do not label outbound clicks as confirmed purchases.
8. Replace the `YOUR-HOMESHIELDTECH-DOMAIN` placeholder in sitemap.xml once the Vercel URL is known.
9. Review legal text for factual accuracy and business-specific requirements. No Google Ads approval is guaranteed.

## Source-derived notes
The catalogue and informational/legal text are adapted from the uploaded Safe Home source. The visual layout and styling are new. No installation, activation, remote troubleshooting, or virus removal is offered.
